# Coding Tracker

A Spring Boot backend that allows users to track coding progress across LeetCode, Codeforces, and GitHub.

## Features

- JWT Authentication
- Spring Security
- PostgreSQL
- Swagger
- REST APIs
- Global Exception Handling

## Tech Stack

Java 21

Spring Boot

PostgreSQL

Spring Security

JWT

Swagger

JUnit

Mockito

## Running

mvn spring-boot:run
